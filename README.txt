# BBextrim — Tienda Ecommerce

Plantilla web estática responsive construida con HTML5, CSS3, JavaScript y Bootstrap 5.3.

## Archivos
- `index.html` — estructura completa de la tienda.
- `style.css` — estilos y adaptación responsive.
- `app.js` — catálogo, filtros, búsqueda y carrito con localStorage.
- `logo1.png` — logo proporcionado para BBextrim.

## Cómo usar
1. Descarga y descomprime el proyecto.
2. Abre `index.html` en un navegador.
3. Para publicar, sube los archivos a GitHub Pages, Cloudflare Pages, Netlify, Vercel u otro hosting estático.

## Antes de producción
- Sustituir los productos demostrativos por el catálogo real.
- Configurar precios y moneda.
- Integrar pasarela de pago.
- Configurar método de envío y cálculo de costos.
- Cambiar WhatsApp, redes sociales y correo por los datos reales.
- Añadir políticas de privacidad, términos y condiciones, cambios/devoluciones.
- Si se requiere administración de productos/pedidos, conectar un backend o servicio ecommerce.

La plantilla usa Bootstrap y fotografías externas de Unsplash para las tarjetas de demostración, por lo que requiere conexión a Internet para cargar esos recursos.
